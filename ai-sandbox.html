AI Sandbox

A space for experiments in progress.

You might be wondering, have I actually shipped AI-involved projects? Yes.

So where are they? I'd love to point to one clean, end-to-end example of designing for AI, with AI, and shipping with AI. But the truth is, my AI work has happened in pieces, some prototyping here, some reviewing there. I'm still learning, experimenting and even getting pushback from stakeholders.

But the curiosity is still there, I assure you. In fact, not having this fully figured out genuinely bothers me. That's why this page exists, to share my AI journey so far.

Beta Mode

This was a request from the client, to find a way to explain to users that this version is beta and that they should expect the screen to change over the next few months. I first designed it in Figma, then took screenshots of my Figma designs and added them to Claude Design to prototype it.

Designed in Figma, prototyped in Claude Design.

I was curious whether Claude Code would do it better, so I prompted it to build the same modal. Claude Design won, though maybe that's because I didn't guide Claude Code enough. It used the wrong colors and landed on an odd grey background. With Claude Design, I could select the design system directly and pick a UI mockup as a starting template. Claude Code, on the other hand, let me use the Figma MCP, so it was technically more accurate.

Brandhub

The design team decided to create something called Brandhub. We realized that with AI we could build our own internal tool to help with design tasks. Brandhub would be the place where we created consistency across our designs for clients, as well as a central hub for design thinking, discovery, and prototyping. As an added function, we made it an MCP so it could be used inside real code.

We started by importing two brands, MIT and Cognia, adding the styling and components for each. But over time, Brandhub started getting too big, and we had to start breaking it down into smaller pieces. For example, instead of design rules living in one Markdown file, we needed to separate them into multiple files.

We hit a wall when we proposed the idea to the dev team, who were understandably apprehensive about designers messing around in their code, especially without strong coding knowledge. So instead of an MCP, I proposed an npm package that developers could install and use themselves. The package contained the setup steps, plus the rules and components of the Cognia design system. Instead of living in a Figma design system, it was all now in Markdown files and a global.css file.
